# EVEREST MOTOR BIKE

Game 3D em three.js, feito para celular na vertical e também jogável no PC.
Desça do cume do Everest até um vulcão em erupção: 17,4 km de neve, gelo, rio, mar, selva e lava.

**By Franciomar Silva** · [@frannciomar](https://instagram.com/frannciomar)

## Controles

**Celular:** dedo na tela acelera, arrastar para os lados pilota, toque duplo aciona o nitro, deslizar no ar faz manobras.

**PC:** W ou ↑ acelera · A/D ou ←/→ pilota · Shift nitro · Espaço pulo · I K J L manobras · C câmera · P pausa.
